# Comparative Analysis of Machine Learning Algorithms for Predicting Vehicle CO2 Emission Class

This project focuses on a comparative analysis of various machine learning algorithms to predict the CO2 emission class of vehicles. The analysis is performed using a dataset of vehicle specifications and their corresponding CO2 emissions.

## Project Structure

- `Classic_Labels/`: Contains analysis and results based on classic labeling techniques.
- `EmissionAnalysis/`: Contains the core data and notebooks for emission analysis.
- `Modules/`: Contains reusable Python modules and classes.
- `Quartile_Labels/`: Contains analysis and results based on quartile-based labeling.
- `Użyte wykresy/`: Contains various plots and charts used in the analysis.

## Getting Started

### Prerequisites

- Python 3.x
- Pip

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/Pawel-Tomasz-Nowak/Comparative-Analysis-of-Machine-Learning-Algorithms-for-Predicting-Vehicle-CO2-Emission-Class.git
    ```
2.  Set up the virtual environment and install dependencies by running the appropriate script for your operating system:

    -   **Windows:**
        ```bash
        setup.bat
        ```
    -   **macOS/Linux:**
        ```bash
        bash setup.sh
        ```
